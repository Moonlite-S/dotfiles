# dotfiles

My custom dotfiles, named Sakura Miku, a pastel pink themed rice configuration.

## Files

- **OS**: MacOS
- **Status Bar**: Sketchy Bar
- **Terminal**: Kitty (Tmux & Starship)
- **Shell**: Zsh
- **Editor**: LazyVim
- **Tile Manager**: Yabai
